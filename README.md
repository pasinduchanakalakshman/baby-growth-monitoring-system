# An AI-Driven Multi-Model System for Early Child Health

## Research Component
Explainable Sequence-Aware AI Framework for Early Prediction of Child Growth Faltering and Personalized Sri Lankan Nutrition Recommendations for Children Aged 0–5 Years Using Digital CHDR Data.

## Architecture Overview
The system uses a Domain-Based Microservices architecture with a React frontend, API Gateway, and specialized microservices for each research component.

## Technology Stack
- Python
- FastAPI 
- MongoDB 
- Docker
- React (Future)
